# Formalne metode - Seminarski rad - Grupa 16
## 📘 Opis projekta
Ovaj repozitorij sadrži **seminarski rad iz predmeta Formalne metode**, čiji je cilj
primjena stečenih znanja iz oblasti testiranja softvera na realnoj web aplikaciji.
U okviru rada implementirani su automatizovani testni slučajevi korištenjem
Selenium WebDriver alata.

Kao predmet testiranja odabrana je **web aplikacija Booking.com**, pri čemu je
fokus stavljen na provjeru osnovnih funkcionalnosti kroz automatizovane
korisničke scenarije.

---

## 🚀 Instalacija i pokretanje

### Korak 1: Instalacija
```bash
npm install
```

### Korak 2: Pokretanje svih testova
```bash
npm test
```
